# University Research Office — Complete Research Management & CMS Portal

Build a complete, production-ready, responsive web application for a University Research Office.

This is NOT just a landing page.

The system must be a complete:

* University Research Office public website
* Research project management system
* Faculty/Professor research portal
* Student research portal
* Research documentation repository
* Research project submission and approval system
* News and announcements CMS
* Events management system
* Research opportunities portal
* Researcher directory
* Faculty profile management system
* Student profile management system
* Research statistics dashboard
* University research administration dashboard
* Fully editable Content Management System

The entire website must be dynamically managed from an administrative dashboard.

⸻

1. DESIGN DIRECTION

Create a premium American university-style academic website inspired by the visual language of New York University.

DO NOT copy NYU’s exact website, logo, copyrighted graphics, or proprietary assets.

Use an original university identity with an NYU-inspired academic violet aesthetic.

Primary color:
#57068C

Secondary colors:
Deep Violet: #330662
Light Violet: #AB82C5
Very Light Violet: #F3EFF7
Black: #000000
White: #FFFFFF
Dark Gray: #404040
Light Gray: #F2F2F2

The NYU brand guidance identifies #57068C as NYU Violet. Use this only as a visual inspiration unless the website is officially authorized to use NYU branding.

Design characteristics:
* sophisticated, academic, modern, minimal, premium, professional, research-oriented, highly readable, responsive, accessible, institutional, clean typography, large editorial photography, subtle animations, strong violet accent, white backgrounds, black typography, generous spacing, modern cards, professional dashboards

Avoid:
* excessive gradients, gaming-style UI, excessive rounded cards, excessive animations, childish colors, clutter, generic startup landing-page appearance

The website should feel like a serious international research university.

⸻

2. TECHNOLOGY STACK

Frontend:
* React, TypeScript, Tailwind CSS, modern component architecture, responsive design, accessible UI

Backend:
* Laravel, REST API, Laravel authentication, Laravel policies, Laravel queues where appropriate, Laravel notifications

Database:
* PostgreSQL / Supabase

Storage:
* Supabase Storage or S3-compatible storage

Authentication:
* Email/password, University email authentication support, Optional Google/Microsoft institutional login architecture, Email verification, Password reset, Two-factor authentication for administrators

Use a clean API architecture. The system must be scalable.

⸻

3. USER TYPES

Create role-based access control.

Roles:
Super Administrator (Full access)
Research Office Administrator
Professor / Faculty Researcher
Student
